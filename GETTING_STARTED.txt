SHOP EASE — Assignment 1 | Android Studio Java + XML

Open this repository's root folder in Android Studio and run the app on API 26+.
App ID: pk.edu.nfciet.shopease
The Android client Firebase configuration is at app/google-services.json.

Firebase project (Android client): shop-ease-228e9.
The Android Google Services Gradle plugin selects the client registered as
pk.edu.nfciet.shopease; another registered Android client may be in the same JSON.
Enable Email/Password in Firebase Authentication and publish firebase.rules
for the Cloud Firestore users/{uid} collection to enable registration/profile storage.
These Firebase Console settings are NOT enabled simply by committing the JSON.

The main branch preserves the five required screen-by-screen assignment commits
from assignment-1. PR #1 was merged without squashing:
https://github.com/RaoFaisal10/ShopEase/pull/1

Do not commit user passwords, Firebase Admin service-account credentials or private keys.
The Android client configuration contains identifiers and an API key; the API key is
not an administrator secret. Restrict Google Cloud API usage appropriately and
enforce Firebase Authentication, security rules, and billing quotas.

Gradle 8.13 / Android Gradle Plugin 8.13.2 / Java 17 / compile SDK 36.
Your local Android Studio ZIP may contain newer IDE-managed Gradle settings.
The repository retains the version successfully compiled on GitHub Actions.
The special gradle-wrapper.jar is a project-local bootstrap for Gradle 8.13.

Generated directories (.gradle, .idea, build), local.properties, .git history
and downloaded SDKs are intentionally not uploaded.
The browser preview, when present, simulates UI and is not live Firebase.
