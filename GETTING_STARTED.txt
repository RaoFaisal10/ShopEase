SHOP EASE - Assignment 1 / Java + XML / Android Studio

Open this folder in Android Studio. The real Firebase configuration is deliberately not fabricated.
For an actual account sign-in and profile saving, create your own Firebase Android project
with package pk.edu.nfciet.shopease, activate Email/Password Authentication, create Firestore,
publish firebase.rules, then save google-services.json to app/google-services.json.

The project can build without that file (login remains disabled until configured).

Build settings: AGP 8.13.2, Gradle 8.13, compile SDK 36, JDK 17, minimum API 26.

The browser-only preview is at preview/index.html and is NOT connected to Firebase.
It simulates screen navigation and validation for visual review only.

Assignment requires a private GitHub repository with instructor collaborator abdullahzafar-336,
branch assignment-1, five exact commits, pull request and APK v1.0 release.
This ZIP contains a local .git repository with all five milestone commits on assignment-1;
no repository was created online and no teacher invitation was sent.

Do not add your real user passwords or Firebase service-account keys to the repository.
